# Restaurant story — "Marketing isn't an extra expense"

40s, 1080×1920 flat 2D cartoon (Remotion), following the reference frame's style:
rounded white-headed characters, thick outlines, warm Lebanese street, sim-game HUD.

| Time | Scene |
| --- | --- |
| 0–5s | The big dream: MY DREAM RESTAURANT, budget $50,000, dream bubble |
| 5–13s | Spending: decor −$15,000, equipment −$20,000, staff −$10,000 |
| 13–19s | Marketing $1,000? Record scratch, wallet grab, red X, "هلّق مش وقتها!", pushed away |
| 19–26s | NOW OPEN… clock races, Day 1: 0 / Day 7: 2 / Day 30: 0, bored staff, tumbleweed |
| 26–31s | Excuses: three speech bubbles, growing frustration, cash hits $0 |
| 31–36s | Lights off one by one, OPEN → CLOSED, FOR RENT, slow zoom out |
| 36–40s | Final message |

No subtitles; the in-scene speech bubbles carry the dialogue.
All music and sound effects are generated by `scripts/gen-audio.mjs`.

```bash
npm i
npm run dev
npx remotion render RestaurantStory out/restaurant-story.mp4
node scripts/gen-audio.mjs
```
