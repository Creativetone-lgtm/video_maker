# CreativeTone — Book a Strategy Call (Reel)

A 34-second, 1080×1920 Remotion Reel showing how easy it is to book a strategy call on creativetoneagency.com.
Built from the real mobile site screenshot, the Outfit brand font and the CreativeTone logo, in an iOS "liquid glass" style.

1. Hook: ~~“Hi, can you help me?”~~ → *There’s a faster way.*
2. Safari: type `creativetoneagency.com` on a glass iOS keyboard
3. The real homepage → tap **Book a Strategy Call** → fast scroll to the form
4. Fill Name / Company / Email / Phone (masked as •••), pick an industry from a glass menu, tap **Start a Project**
5. Request sent ✓
6. iOS incoming call: **CreativeTone — Strategy call…** → answered
7. Outro: *Just book. We’ll be ready for the call.* + logo, domain and CTA

Music (120 BPM, original and royalty-free) and all sound effects are generated by the scripts below; scene cuts land on the beat.

## Commands

```bash
npm i
npm run dev                                   # Remotion Studio preview
npx remotion render BookingReel out/creativetone-booking-reel.mp4
node scripts/gen-music.mjs                    # regenerate public/music.wav
node scripts/gen-sfx.mjs                      # regenerate the sound effects
```

Each scene is registered on its own under **Scenes** in Studio, with captions, headlines, industry and CTA editable as props.
`public/site/` holds the full-page screenshot split into 3000px chunks; `public/logo-*.png` were extracted from it.
